## Stack

- **Framework** — Next.js 16 (App Router, Turbopack)
- **Language** — TypeScript
- **Styling** — Tailwind CSS, ShadCN UI
- **Animations** — Framer Motion
- **3D / WebGL** — Three.js, OGL, React Three Fiber
- **Fonts** — Instrument Serif (Google Fonts)
- **Deployment** — Vercel
- **Domain** — GoDaddy → `suhag.xyz`

## Getting Started

```bash
git clone https://github.com/Suhagshetty/portfolio
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

### Build for production

```bash
npm run build
npm run start
```
